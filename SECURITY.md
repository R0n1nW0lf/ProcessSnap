# Security and Responsible Testing

ProcessSnap is intended for defensive security, malware-analysis, and controlled lab workflows.

## Public Issues

When reporting a bug or requesting a feature, please include only the information needed to reproduce or understand the issue.

Useful details include:

- ProcessSnap version
- Windows version and architecture
- Expected behavior
- Actual behavior
- Error message, if any
- Sanitized screenshot or log, if appropriate

## Do Not Upload

Do not upload or paste any of the following into public GitHub Issues or discussions:

- Live malware samples
- Credentials, tokens, API keys, or passwords
- Private case files
- Sensitive process evidence
- Personal information
- Confidential organization data
- Unsanitized logs containing sensitive paths, usernames, hostnames, or network details

## Testing Guidance

Run unknown or potentially malicious software only in an appropriate isolated lab or sandbox.

ProcessSnap records process-lifecycle evidence. A recorded process or behavior is not automatically malicious; analysts should correlate and verify evidence before reaching a conclusion.
